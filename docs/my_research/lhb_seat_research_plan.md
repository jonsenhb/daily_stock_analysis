# 龙虎榜与席位画像研究计划（LHB Seat Research Plan v0）

本文档定义 **A 股龙虎榜 + 营业部（席位）画像** 的研究范围、数据契约与方法论边界，供后续在 `src/my_research/lhb_seat_profile.py` 等处实现时对照。

- **单一真源**：字段名、限量、积分门槛以 Tushare 官网为准，开发前须再次打开对应页面核对。
  - [龙虎榜每日明细 `top_list` · doc_id=106](https://tushare.pro/document/2?doc_id=106)
  - [龙虎榜机构明细 `top_inst` · doc_id=107](https://tushare.pro/document/2?doc_id=107)
- **不替代官网**：凡官网 **未写明** 的更新时点、频次等，本文标注为「未载明」，**不臆测**；与 [积分与频次 · doc_id=290](https://tushare.pro/document/1?doc_id=290) 取 **更保守** 一侧实现限流。
- **项目边界**（与 `AGENTS.md` 一致）：本计划用于 **研究、复盘、统计与风险提示**，**不**输出确定性买卖建议，**不**接自动下单；所有结论须带 **样本量、不确定性、失效条件**。

---

## 1. `top_list` 用途

- **事件宇宙（股票层）**：按交易日枚举「当日上了龙虎榜的标的」，得到 `trade_date`、`ts_code`、`reason`、价格与量能、龙虎榜买卖汇总等。
- **上榜质量描述**：如龙虎榜成交额占比、净买入占比、流通市值等，用于区分「榜上大换手」与「榜额相对总成交流不大」等情境。
- **与 `top_inst` 对齐的主键**：同一 `trade_date` + `ts_code` 下，股票层明细可与席位层明细关联（注意 **一行股票可能对应多行席位**，且 `reason` 在官方样例中存在同一标的多条记录的情况，合并策略需在实现中单开一节）。
- **为事件研究定 T 日**：通常取 **龙虎榜披露日**（`trade_date`，收盘后可知）为事件日 **T**；后续收益从 **T+1 及以后交易日** 起算（见第 8 节）。

---

## 2. `top_inst` 用途

- **席位层明细**：在已知上榜标的的前提下，查看 **营业部名称 `exalter`** 的买入额、卖出额、净买卖、买卖类型 `side` 以及对应 `reason`。
- **席位画像的数据原料**：对 `exalter` 做聚合得到「某席位历史上榜后的_forward 表现分布」「买卖方向偏好」「与机构/游资常用标签的共现」等（指标见第 9 节）。
- **与 `top_list` 的分工**：`top_list` 回答「谁上榜、为何上榜、榜单强度」；`top_inst` 回答「哪些席位在买/卖、金额与占比结构」。

**命名说明**：官方接口名含「机构」，但输出字段为 **营业部名称**；研究上统一称 **席位 / exalter**，避免窄义「机构」语义误导。

## 3. 字段解释

### 3.1 `top_list`（官网输出参数表摘要）

| 字段 | 类型（官网） | 含义与研究注意点 |
|------|----------------|------------------|
| `trade_date` | str | 交易日期（榜单日 T） |
| `ts_code` | str | TS 股票代码 |
| `name` | str | 股票名称 |
| `close` | float | 收盘价 |
| `pct_change` | float | 涨跌幅 |
| `turnover_rate` | float | 换手率 |
| `amount` | float | 总成交额 |
| `l_sell` | float | 龙虎榜卖出额 |
| `l_buy` | float | 龙虎榜买入额 |
| `l_amount` | float | 龙虎榜成交额 |
| `net_amount` | float | 龙虎榜净买入额 |
| `net_rate` | float | 龙虎榜净买额占比 |
| `amount_rate` | float | 龙虎榜成交额占比 |
| `float_values` | float | 当日流通市值 |
| `reason` | str | 上榜理由（文本，可做多事件分层） |

**输入参数**：`trade_date` **必选**；`ts_code` 可选。

### 3.2 `top_inst`（官网输出参数表摘要）

| 字段 | 类型（官网） | 含义与研究注意点 |
|------|----------------|------------------|
| `trade_date` | str | 交易日期 |
| `ts_code` | str | TS 股票代码 |
| `exalter` | str | 营业部名称 |
| `side` | str | `0`：买入金额最大的前 5 名；`1`：卖出金额最大的前 5 名 |
| `buy` | float | 买入额（元） |
| `buy_rate` | float | 买入占总成交比例 |
| `sell` | float | 卖出额（元） |
| `sell_rate` | float | 卖出占总成交比例 |
| `net_buy` | float | 净成交额（元） |
| `reason` | str | 上榜理由 |

**输入参数**：`trade_date` **必选**；`ts_code` 可选。

**限量（官网明确）**：单次请求 **最大返回 10000 行**，需按参数循环获取全量历史。

## 4. 数据更新时间

- **官网接口页（106 / 107）正文**：在当前抓取版本下 **未载明** 精确入库时刻（与 `docs/my_research/tushare_data_plan.md` 矩阵一致）。
- **工程假设（须标注为假设而非事实）**：
  - 龙虎榜数据通常随 **当日收盘后清算与披露节奏** 才能稳定，不宜当作盘中实时信号。
  - 与 `daily`「交易日 15–17 点入库」等对齐时，**以实际拉取成功的 `fetched_at` 为准** 记录「数据可得时间」。
- **实操**：新交易日盘后拉取；若返回空或不完整，应 **重试 + 记录**，避免把「未更新」误认为「当日无榜」。

## 5. 权限要求

- **`top_inst`（官网）**：用户需要 **至少 5000 积分**才可调取（见 doc_id=107 原文）。

- **`top_list`（官网 doc 106）**：正文未见单独积分句；实现时以 **实际调用与账号提示** 为准，并在烟测脚本中覆盖。

## 6. 本地缓存策略

与 `docs/my_research/tushare_data_plan.md`、 `docs/my_research/tushare_cache.md` 对齐，建议：

1. **分区键**：按 **`trade_date`** 分区落盘（Parquet/SQLite manifest 等现有研究缓存模式均可）；可另存 **`ts_code`** 请求切片以便增量补全。
2. **`top_inst` 体积**：单日全市场行数可达 **万级**，必须 **分页/循环** 直至无新行；对请求参数做 **哈希** 与 **`fetched_at`** 元数据，保证幂等。
3. **字段裁剪**：使用 `fields=` 显式列清单，避免官网增列导致静默错位；Schema 带版本号。
4. **与行情 joint**：`daily` / `trade_cal` / `suspend_d` 等 **独立分区**；合并时只通过键连接，**不把未来日期的行情写回 T 日分区**。
5. **多数据源（后续 AKShare / 东财）**：若引入第二来源，须保留 `source` 与口径说明，**禁止**无标识混并为单表事实。

## 7. 如何避免未来函数

1. **固定信息集**：在事件日 **T**，允许使用的仅应为 **T 日收盘后`、`数据拉取时间之前` 在业务上可得的信息集合；实现上用 **`trade_date ≤ T` 的行情与榜单**。
2. **收益起点**：任何「上榜当日收盘买入/卖出」的假设，若用于统计，须在文档中 **显式声明**；默认研究收益从 **T+1 开盘或 T+1 收盘** 起算（择一固化，全样本一致），且 **不得使用 T 日未知成交量价**。
3. **停牌与非交易日**：用 `trade_cal` 递推 **真实交易日**，配合 `suspend_d` 剔除不可交易时段；`forward` 窗口内若 **有效交易日不足 k 个**，该样本 **作废或单独标记**，不可沿用日历自然日凑数。
4. **基准与板块**：计算超额收益时，基准指数与行业/概念板块数据须 **同日可得**；板块标签若用 **T+1 才重构的成分**，须禁止。
5. **财报/公告**：本计划首版不依赖重大公告时刻；若扩展至重合事件，须用 **披露时间戳** 再砍一刀。
6. **元数据**：每条聚合结果附带 `as_of`（数据快照时间）与 `rule_version`，便于审计。

---

## 8. D+1 / D+3 / D+5 标签

本节指 **事件发生后的「第 1 / 3 / 5 个交易日」**（非自然日），且须在同一套日历规则下全局一致。

| 标签 | 定义（建议默认） | 用途 |
|------|------------------|------|
| **D+1** | T 之后 **第 1 个** `is_open=1` 且标的未处于不可用交易状态的交易日 | 短窗异动、隔夜情绪 |
| **D+3** | T 之后 **第 3 个** 有效交易日 | 常见短线持仓观察窗之一 |
| **D+5** | T 之后 **第 5 个** 有效交易日 | 略延长窗，降低单日噪音权重 |

**收益定义（须在代码里二选一并写死文档）**：

- **收盘到收盘**：`close[T+k] / close[T] - 1` 或相对 `open[T+1]` 等；首版推荐 **T+1 至 T+k 收盘复合收益**，避免 T 日已上榜的收盘价争议。
- **超额收益**：对同一窗口计算 **相对基准**（如沪深300）或 **行业收益中位数** 的超额部分。

**输出要求**：每条统计须说明 **窗口定义**、**停牌处理**、**缺失率**。

## 9. 席位画像指标

以下指标均在 **避免未来函数** 前提下，对 `exalter` 在滚动历史样本上计算；首版 **全部描述性统计**，不做「必胜席位」判定。

- **参与度**：上榜次数、上榜涉及标的数、买入侧/卖出侧出现频次（`side`）。
- **金额结构**：`buy`、`sell`、`net_buy` 的分布（中位数、分位）；净买入占比与 `top_list.net_rate` 的联合分布。
- **方向与理由分层**：按 `reason` 分组后的上述统计（样本量须单独列示）。
- **持仓风格标签（启发式，非结论）**：如「偏多净买」「偏多净卖」「大额对倒嫌疑」等，仅作 **risk_flags**，须附 **反例说明**。
- **与标的层联动**：同源 `ts_code` 在 D+1/D+3/D+5 的收益分布，分层到「该席位当日净买/净卖」。
- **机构/游资共现**（可选）：多席位同日同向净买——仅作 **结构描述**，因果不解读。

## 10. 事件研究方法

1. **定义事件**：如「席位 S 出现在 `top_inst` 且 `net_buy > 阈值` 且 `reason ∈ R`」；阈值与 R **预先注册**，忌数据窥探后改规则。
2. **样本池**：全市场龙虎榜子样本或按市值/上市板块过滤；过滤条件 **在 T 日可得**。
3. **基准选择**：宽基指数 + 可选行业中性组合；报告 **基准敏感性**（换基准后结论是否脆弱）。
4. **统计量**：均值、中位数、分位、胜率、最大回撤（窗口内）；可报告 **Newey-West** 或 bootstrap 置信区间（实现阶段再定复杂度）。
5. **分组对照**：无龙虎榜对照组需谨慎（选择性偏差），可采用 **倾向得分/市值行业匹配** 的简化版或明确 **不做因果仅做关联**。

---

## 11. 样本量要求

- **席位级**：单席位 **最少事件数 N_min**（建议默认 **≥ 30** 才展示聚合分布；**< 30** 仅展示原始计数 + 「样本不足」标记）。N_min 可配置。
- **理由分层**：每层须满足更小下限（如 **≥ 10**），否则合并为「其它」或不输出分位数。
- **时间跨度**：至少覆盖 **牛/熊/震荡** 中两类以上（用第 12 节切片验证），否则标注 **制度或环境外推风险**。
- **报告格式**：必须输出 `n_events`、`n_stocks`、`date_range`、`missing_forward_count`。

---

## 12. 市场状态切片

与 `market_gate` 输出或指数行情对齐，将事件按 **大盘状态** 分层，例如：

- 指数 **20 日收益** 分位：高位 / 中位 / 低位；
- **波动率分位**：高波动 vs 低波动；
- **成交额/情绪代理**（如连板家数、涨跌停比）分位。

每层单独统计 D+1/D+3/D+5，**禁止**跨层混报为单一数字。

---

## 13. 板块状态切片

- 标的 **行业/概念** 热度：使用 **T 日或 T-1 日可得** 的板块涨跌幅、成交额占比、涨停家数等（数据源须与第 7 节一致）。
- 报告 **板块样本量**：热门板块内事件往往更密，须警惕 **重复贡献**（同一板块连日上榜）。

---

## 14. 风险：样本少、幸存者偏差、规律失效**

| 风险 | 说明 | 缓解与披露 |
|------|------|------------|
| **样本少** | 龙虎榜及单席位事件稀疏，尤其细分 `reason` 后 | 强制 N_min；输出信心等级；不提供个股级「预测」 |
| **幸存者偏差** | 历史席位更名、注销、合并；退市标的不可追踪 | 记录 `exalter` 规范化版本；退市后收益链断裂单独计数 |
| **多重检验** | 多席位、多窗口、多切片导致「碰巧显著」 | 预选主假设；报告探索性分析为 secondary；可选简单 FDR 说明 |
| **微观结构与市场制度变更** | 涨跌停、龙虎榜披露规则、交易机制变化 | `rule_version`；分年度稳健性检验 |
| **规律失效** | 历史统计不构成未来收益承诺 | 每条输出 **失效条件**（如环境剧变、样本枯竭、相反证据出现） |
